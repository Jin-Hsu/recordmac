# 安装、权限与排查

## 下载哪个文件？

Apple Silicon + macOS 15 以上下载 Release 中的 `.dmg`。GitHub 的 Source code 是源码，不是可运行安装包。Intel 和旧 macOS 暂未提供已验证的安装包。

## macOS 阻止打开

目前没有 Developer ID 签名与 Apple 公证。确认下载自本项目，核对 SHA-256 后，可在「系统设置 → 隐私与安全性」查看是否提供「仍要打开」，按系统提示操作。不要关闭系统级 Gatekeeper，也不需要安装虚拟声卡。

## 已打开录屏权限仍提示无权限

先确保应用已放在 Applications，并退出其他位置的同名副本。在「屏幕与系统音频录制」中重新选择当前 App，再退出并重开。临时签名、路径变化或更新可能使旧权限记录失效，固定名称不保证保留权限。

## 保存失败或停止后一直等待

等待合成结束，检查磁盘空间与保存目录。避免反复点击停止。当前测试版仍可能遇到系统回调和文件写入异常。记录错误信息并提交 Issue；临时目录中可能保留原始素材，可用于本地恢复，不要上传公开仓库。

## 声音回声或不同步

同时录制系统声与人声时推荐戴耳机。蓝牙设备与设备延迟可能影响结果。摄像头同步目前基于启动时间估算，请先做短录测试；长录同步仍待验证。

## 可以商用吗？

当前按 CC BY-NC 4.0 发布，商业用途需要另行许可。请通过仓库 Issue 联系维护者讨论授权，不要附私人合同或付款信息。
